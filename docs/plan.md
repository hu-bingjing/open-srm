# 分阶段开发与验收计划

每阶段交付可复现命令、实际测试记录和限制。阶段通过不自动授权生产连接、公开仓库或 ERP 写入。Phase 00 的可运行产物是设计规格检查；Phase 01 起必须实际运行服务，业务阶段不能以静态页面或本规格代替。

| 阶段 | 可交付结果 | 必须执行的验收 | 前置 |
| --- | --- | --- | --- |
| 00 | PRD/架构/权限/ERD/API/ERP 端口/计划；可执行规则规格；安全与 CI 基线 | 文档与契约检查、规则正负向测试、敏感扫描、标准 OpenAPI 校验；记录不含应用运行 | 工作区检查 |
| 01 | Maven Wrapper Java 21/Spring Boot 工程、Vue 工程、锁文件、Flyway、Compose/Nginx、登录/会话/角色/动作、审计/幂等基础 | 干净构建、Compose 健康、迁移、真实登录/注销/失效/CSRF/401/403、JUnit、Postgres Testcontainers、Playwright 登录；禁止固定口令 | 00 |
| 02 | 多公司/工厂/采购组织、供应商关系、授权元组与供应商绑定 | CRUD 持久化；跨公司/跨供应商/列表计数/批量越权全拒绝；刷新重启数据保留 | 01 |
| 03 | 七端口 Java 接口、可运行 Mock、订单头行计划行/版本、同步任务 | 重复/乱序/版本冲突/断点续传/取消/同版本异内容；从 Mock 同步到真实 Postgres 并用前端查看 | 02 |
| 04 | 部分确认、交期申请、审批、交货计划 | 60+40 部分确认、自批拒绝、过期版本拒绝、重复审批、计划数量不超额、事务回滚；真实页面+API | 03 |

| 07 | 工作台、站内通知、组织内统计 | outbox 重放去重、权限过滤、已读归属、统计口径与数据库对账、失败重试 | 05（SAP 可独立补验） |
| 08 | 自动化回归、安全/依赖与许可审查、备份恢复、部署验收 | CI 全通过、干净机器独立部署、跨域渗透用例、性能实测、离线恢复与数量核对、恢复时间记录、上线清单 | 前述功能；生产另授权 |

## 当前边界与下一阶段工作包

2026-11-10 用户最新范围：独立主机部署/恢复不需要；GitHub 推送及云端 CI 暂缓。当前一期（Phase 00–08）功能开发与既有 Ubuntu 内部测试部署已完成。SAP 真实业务对账因空壳系统无数据待补验；PRD 的 10 万订单行/50 并发生产规模目标尚未实测，不以 2,655 行/10 并发的读取测试替代。后者是验收边界，不将取消/暂缓事项继续列为当前开发阻塞。

Phase 00 已通过设计验收；Phase 01–05 已完成现有测试实例部署、数据库与页面验收，见阶段记录。不能用 Python 规格替代后端测试。Phase 06 SAP 只读适配及同步管理已实现，Ubuntu 内部验收通过，真实业务数量对账因当前可见数据为空待补验。Phase 07 工作台、站内通知与组织内统计已完成测试部署验收，见 [Phase 07 验收](acceptance/phase-07.md)。Phase 08 内部回归、安全检查、主实例升级、新卷恢复及性能实测已完成，外部门槛见 [Phase 08 验收](acceptance/phase-08.md)。
版本和完整命令见安装说明；新增 Maven/npm/Docker Dependabot 及分层 CI。未创建 GitHub 远端，不宣称云端 CI 已运行。
Phase 05 结果见 [验收记录](acceptance/phase-05.md)。本轮已授权 Phase 06 及 Ubuntu 测试实例部署，以及此前 SAP 测试环境的真实业务只读样本查找；结果与外部验收缺口见 [Phase 06 验收](acceptance/phase-06.md)。本轮已授权并完成 Phase 07 及既有 Ubuntu 测试实例部署验收；Phase 08 已完成内部测试部署验收；云端 CI、第二主机/异地恢复及公开/生产门槛仍待独立验收，生产部署、生产 ERP 及 ERP 写入仍未授权。

## 发布门槛

没有默认许可证；公开前许可证选择、人工代码审查、完整 Git 历史扫描、依赖许可证清单必须完成。
GitHub Secret Scanning/Push Protection 需仓库创建后按账号能力核验；本地配置不能视作已启用服务端功能。
无高危未解决安全问题、无真实业务/身份/地址数据、无真实凭据。第一期业务完成与正式公开是两次独立验收。
