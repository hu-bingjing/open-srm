## 安全、依赖与许可

Maven 125、npm lock 99、Python 开发工具 41 项无已知依赖漏洞。最终三个实际运行镜像均为全部已知漏洞 0、秘密命中 0，运行镜像 ID 与扫描 ID 逐一一致。初扫发现 Web 系统包高危/严重、数据库旧 Go gosu 高危；更新固定摘要的 Web 基础镜像，删除 gosu 并直接采用 su-exec。随后三个镜像的 zlib 中危通过稳定仓库精确版本 1.4-r0 修复，未抑制 CVE。PostgreSQL 引擎仍为 17.11，已验证新卷初始化、原卷启动及恢复。

完整许可声明清单：125 Maven /99 npm /41 Python，未解析声明 0；16 项条款候选需人工按分发方式审查。镜像许可声明 API 211、Web 108、数据库 61；没有将自动声明清点解释为法律审核。项目许可证未选择。Actions 固定完整 SHA，Python 全量开发依赖锁定，CI 增加镜像扫描、恢复及副本性能步骤；尚未建立/上传远端，因此无云端 CI 实际结果。
