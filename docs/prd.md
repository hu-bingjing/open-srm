# 产品需求基线 — Phase 00

## 定位和边界

OpenSRM 服务制造业集团的供应商协同。第一期一个实例属于一个部署集团；支持多个法人公司、工厂、采购组织及跨公司供应商。
企业身份、地址、品牌、ERP 凭据及编号映射全部外置。演示只用 Company A、Company B、Plant A、Supplier A 等虚构数据。
预留部署级 `deployment_id` 与外部系统标识，不实现 SaaS 多租户计费、租户自助开通或隔离数据库。

默认假设：ERP 管订单及实际收货的权威数据；SRM 管供应商协同、审批与 ASN。第一期不在 SRM 新建或修改 ERP 采购订单。
数量统一按订单基本计量单位，使用十进制定点数，首期不自动转换单位、不允许超送；单位不一致、负数或未知物料进入同步异常队列。
日期为业务组织当地日期；事件时间为 UTC。默认中文 UI，内部状态码/API 字段为英文。
这些假设是实现基线，可在后续阶段按授权需求修订。

## 用户与主流程

- 集团管理员：维护组织、用户、角色和授权，不能仅凭管理员角色读取全部业务数据。
- 采购员：查看其组织订单、处理供应商协同、审批被授权的交期变更（申请者不得审批自己的申请）。
- 采购审批人：在授权公司/工厂/采购组织内审批变更。
- 供应商用户：仅访问绑定供应商在已授权组织下的订单、确认、计划和 ASN。
- 收货查看者：查看授权范围的 ERP 收货与差异，不在 SRM 手工记实际收货。
- 集成运维员：查看脱敏同步任务、重试指定作业，不因此取得全部订单或供应商资料权限。
- 审计员：只读授权范围审计，不可修改业务或审计。

主流程：Mock/ERP 同步组织与供应商 → 同步版本化订单/行/计划行 → 供应商逐计划行部分确认 → 延期申请与采购审批 → 生成分批交货计划 → 供应商提交 ASN → ERP 收货/冲销同步 → 对账数量与异常提示。
ASN 提交成功仅表示发货通知已受理；ERP 未回传收货时不显示已收货。

## 页面与交互范围

计划页面：登录、工作台、公司/工厂/采购组织、供应商、订单列表/详情（版本/行/计划行/确认/收货）、待确认、交期申请与审批、交货计划、ASN、实际收货、通知、用户与授权、审计、同步任务及异常。
列表服务端分页及过滤；详情操作根据权限和业务状态启用，后台仍完整校验。确认/延期/ASN 提交前展示目标版本、数量与业务日期。失败提示包含可定位的错误码和请求 ID，不展示 SQL、堆栈或外部系统凭据。

## 非功能验收目标（尚未测试）

- 安全：默认拒绝；对象级授权；HTTPS；HttpOnly/SameSite 会话 Cookie 与 CSRF；口令用自适应哈希；禁止固定演示密码进入生产。
- 事务：数量变更行锁/乐观锁；审计和 outbox 同事务；ERP 调用事务外执行；写入重放无副作用。
- 规模基线：10 万订单行、50 并发会话，常规分页查询 p95 < 1 秒、协同写 p95 < 2 秒（不含外部 ERP）；Phase 08 提供负载和硬件实测，不能提前宣称达标。
- 可恢复性目标：RPO ≤ 24 小时、RTO ≤ 4 小时；实际值以恢复演练为准。备份包含数据库、私有配置与文件引用映射，密钥独立保管。
- 可维护性：模块依赖检查、自动化契约与负向权限测试；API 向后兼容，破坏性变更使用新版本。

## 后续范围

第二期：询报价、合同、质量、对账、绩效。第三期：AI 分析、微信小程序、更多 ERP 连接器。
第一期不包含上述模块、ERP 主数据编辑、财务过账、生产系统自动写入或 SaaS 租户管理。

## Phase 02 实现边界

ORG-01/SUP-01/IAM-01 的组织与供应商子集已实现：多组织目录、供应商多公司服务、冻结/关系停用、显式公司范围与供应商绑定。冻结供应商可读历史；阻止新确认/ASN 的业务写入校验将在对应模块实现时验收。完整 SaaS、多层供应商门户、采购订单及 ERP 同步不计入本阶段。

## Phase 03 实现边界

PO-01/PO-02 的订单头/行/计划行与版本子集、INT-01 的七个 Java 端口和 Mock 订单同步已实现；采购订单由来源导入并按行授权。版本冲突与取消后重开进入一致性冻结，不删除历史。确认/交期/ASN/收货及真实 SAP 连接尚未实现，跨模块数量和失效仍待对应阶段验收。

## Phase 04 实现边界

CONF-01/CHG-01 的部分确认、延期预占/采购审批、已生效承诺改期和派生计划已实现，落实来源与本地版本、数量、幂等及数据权限。订单新版本原子失效旧协同。草稿保存、发货/收货和真实 ERP 发布尚未实现；交货计划不作为实际收货依据。

## Phase 05 实现范围

ASN 多行草稿、编辑、提交、取消及分批送货；独立 ERP 实际收货、明确分配、部分/全额冲销和分页同步监控已实现。页面分别显示送货预留、净收货和在途，实际收货不能由 ASN 或人工业务写接口创建。真实 SAP 和外部 ASN 发布/受理尚未接入，当前使用 Mock Provider 及虚构数据验收。来源变更存在历史发货/收货时保守冻结，人工解除冻结/通用映射编辑器另行规划。
